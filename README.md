# iTech Univ Plus Admission Form

A student project that updates an original HTML-only college admission form using HTML, CSS, and vanilla JavaScript. The form keeps the original institute details and application sections while making the layout easier to use on desktop and mobile.

**Tagline:** “The right place for excellency”

## Live demo

[Open the admission form](https://prapdt-code.github.io/itech-univ-plus-admission-form/)

## What’s included

- Student, parent, contact, and education details
- Course, tuition, and class-time choices
- Browser-based required-field and email validation
- Responsive styling and a clear-form button

## Project files

- `index.html` — form structure and fields
- `style.css` — colors, layout, and responsive styles
- `script.js` — date default and form feedback

## Run it on your computer

Download the three files into the same folder, then open `index.html` in your browser. No framework or server is required.

## Note

This is a front-end demonstration. The Save application button checks the form and shows a message, but it does not send or store application details.
